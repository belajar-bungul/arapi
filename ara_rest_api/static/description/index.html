Installation & Setup

Get up and running in 6 simple steps.

1

Add Addon Path

Add the module parent folder to your Odoo configuration file under addons_path.

2

Update Apps List

Activate Developer Mode in Odoo 19 and click Apps > Update Apps List.

3

Install Module

Search for ARA REST API (ara_rest_api) in the Apps menu and click Install.

4

Open Token Settings

Navigate to Settings > REST API > API Tokens inside your Odoo backend.

5

Configure Access

Create a token, assign it to a designated Odoo user, and configure the list of allowed models and permissions.

6

Generate Secret Token

Generate the token secret and store it in your secret manager. Note: The full secret value is shown only once!

Authentication

Header-Based Bearer Token Auth

Send your generated token in the HTTP Authorization header with every API request. Requests without a valid token header will be rejected immediately.

// HTTP Request Header Example
Authorization: Bearer ara_your_token_value_here
API Reference

Available REST Endpoints

Base Path: /api/v1

Method Endpoint Path Description & Behavior
GET /api/v1/models Lists all Odoo models authorized for the provided token.
GET /api/v1/<model> Lists records with optional domain filters, field selection, and pagination limits.
GET /api/v1/<model>/<id> Retrieves detailed fields for a single record by ID.
POST /api/v1/<model> Creates a new record (requires active Create permission on token).
PUT / PATCH /api/v1/<model>/<id> Updates an existing record (requires active Write permission on token).
DELETE /api/v1/<model>/<id> Deletes a record by ID (requires active Delete permission on token).

Example GET List Request with Filters & Pagination

GET /api/v1/res.partner?fields=name,email&limit=20&offset=0&domain=[["is_company","=",true]]
Security Engine

Multi-Layered Protection

Never compromise your core Odoo ERP security.

Token Allowlist

Explicitly specify which Odoo models can be accessed per token. Unlisted models return access errors.

Odoo User Permissions

Requests execute in the context of the assigned Odoo user, respecting security groups and ACLs.

Record Rules

Native Odoo multi-company and Record Rules automatically filter data output per request.

Field Allowlists

Restrict readable and writable fields to prevent exposing sensitive attributes (e.g. passwords, secrets).

Domain & Limit Constraints

Enforce forced domain constraints and maximum query pagination limits to prevent server memory overload.

Token Expiration

Set strict expiration dates on tokens for temporary integrations or partner access revocation.
